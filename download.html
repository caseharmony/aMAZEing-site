Before you start

What you'll need

Short version: a keyboard and a little free space. Everything else is optional.

Operating system

Windows 10 or 11 (64-bit), or a modern 64-bit Linux distribution for the AppImage.

Disk space

Around 65 MB free. The app is portable, so it won't scatter files across your system.

Controls

The game is played with the arrow keys. No controller, no mouse and no setup required.

Network

Only for sign-in and cloud saves. Local play and local saves work completely offline.

Questions

Good to know

Still stuck? The issue tracker is the place to ask.

Do I need an account to play?

No. You can generate mazes, play, save locally and export images without signing in. An account is only for cloud saves and syncing across machines.

Is aMAZEing free?

Yes, the builds are free to download from GitHub. The source code is public in the Maze-Game repository.

Why does Windows show a warning?

The executable isn't code-signed, so Windows SmartScreen treats it as unknown. Click More info then Run anyway, or verify the SHA-256 checksum above. You can also inspect and build the source yourself.

Will there be a macOS build?

There isn't one in the current release. Watch or star the repository on GitHub to see future releases as they land.

How do I update to a newer version?

Just download the new build and replace the old file. Your local saves stay put; if you use cloud saves, they'll follow your account.
